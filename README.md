# Targeting UWP / Xbox (UWP)

UWP / Xbox UWP support lives in a separate repository: **[Cocos2D-Mono/Cocos2D-Mono.UWP](https://github.com/Cocos2D-Mono/Cocos2D-Mono.UWP)**. The NuGet packages [`Cocos2D-Mono.Uwp`](https://www.nuget.org/packages/Cocos2D-Mono.Uwp/) and `Cocos2D-Mono.Box2D.Uwp` are published from there.

The UWP repo pins to a specific mainline commit via git submodule and pins MonoGame to `MonoGame.Framework.WindowsUniversal 3.8.1.303` (the final UWP-supporting release). Future modernization work in mainline does not affect UWP consumers.
